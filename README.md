# 🎧 Spotify vs YouTube: Análise Comparativa de Desempenho Musical

Este projeto de ciência de dados tem como objetivo analisar e comparar o desempenho de músicas nas plataformas **Spotify** e **YouTube**. Através de uma abordagem exploratória, tratamos os dados, removemos inconsistências e realizamos análises estatísticas e visuais para entender os padrões de consumo em cada plataforma.

---

## 📁 Sobre o Dataset

O conjunto de dados contém informações sobre faixas musicais, incluindo:

- Métricas de áudio (como *Danceability*, *Energy*, *Valence*, etc.)
- Popularidade no YouTube (*Views*, *Likes*, *Comments*)
- Popularidade no Spotify (*Stream*)
- Duração, tom, intensidade sonora e mais


---

## 📊 Principais Etapas do Projeto

- Importação e visualização dos dados
- Tratamento de valores nulos
- Análise estatística descritiva
- Visualizações interativas com Plotly e Seaborn
- Comparação entre desempenho no YouTube vs Spotify

---

## 📌 Principais Descobertas

- A média de visualizações no YouTube é muito maior que a mediana, indicando forte assimetria.
- A distribuição de streams no Spotify apresenta características diferentes das métricas do YouTube.
- Métricas como *Danceability* e *Energy* estão relacionadas com maior engajamento nas plataformas.

---

## 🛠️ Tecnologias Utilizadas

- Python (Pandas, NumPy)
- Visualização: Seaborn, Matplotlib, Plotly
- Jupyter Notebook
